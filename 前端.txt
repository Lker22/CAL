项目分为 5大核心模块 ，每个模块对应独立的视图、API和状态管理：

模块名称 路径 功能描述 
1.用户与学习画像   /user/ , /profile/  用户登录注册、学习画像构建与展示 
2.AI多智能体资源生成 /agent/ , /resource/ 智能体管理、学习资源生成（文档/思维导图/题库等） 
3.学习路径规划 /path/ , /recommend/ 个性化学习路径生成、步骤管理、资源推荐 
4.智能辅导 /tutor/ AI答疑、多模态提问、答疑历史 
5.学习效果评估 /assessment/ , /learning/ 评估报告、学习统计、薄弱点分析

## API接口总览（后端需实现）
### 3.1 用户模块 (src/api/user.js)
API路径     HTTP方法          功能            请求参数 
/user/login  POST         用户登录   { username, password } 
/user/register    POST  用户注册    { username, password, email, nickname } 
/user/info      GET        获取当前用户信息             - 
/user/info    PUT          更新用户信息 { nickname, email, avatar, phone } 
/user/password    PUT   修改密码 { oldPassword, newPassword }
 /user/logout    POST    退出登录

### 3.2 学习画像模块 (src/api/profile.js)
API路径          HTTP方法      功能           请求参数  
/profile           GET        获取学习画像 - 
/profile          PUT         更新学习画像 画像维度数据 
/profile/build/start      POST         开始画像构建对话 - 
/profile/build/chat       POST          发送画像构建消息 { message, context } 
/profile/build/stream   POST    流式构建画像(SSE) { message, context } /profile/chat/history     GET     获取画像构建历史 - /profile/reset POST 重置画像

### 3.3 学习资源模块 (src/api/resource.js)
API路径         HTTP方法        功能        请求参数 
/resource/agents GET 获取智能体列表 - 
/resource/agents/{agentId}    GET    获取智能体详情   agentId 
/resource/generate       POST         生成学习资源(异步) { agentId, resourceType, topic, params } 
/resource/generate/progress/{taskId}   GET  获取生成进度    taskId 
/resource/list          GET       获取资源列表     { type, keyword, page, pageSize } /resource/detail/{resourceId}    GET      获取资源详情 resourceId /resource/{resourceId}   DELETE         删除资源       resourceId /resource/download/{resourceId}  GET    下载资源   resourceId

### 3.4 学习路径模块 (src/api/learningPath.js)
API路径 HTTP方法 功能 请求参数 
/learning-path/generate    POST   一键生成学习路径   { subject, goal, duration } /learning-path/list    GET    获取学习路径列表       { page, pageSize, status } 
/learning-path/detail/{pathId}   GET   获取路径详情(含步骤)     pathId 
/learning-path/step/{stepId}/complete    POST  完成学习步骤(打卡) { duration, notes, score }
/learning-path/{pathId}/recommend     GET    获取智能资源推荐    pathId 
/learning-path/{pathId}/adjust      PUT   动态调整学习路径 { adjustmentType, params } /learning-path/{pathId}         DELETE     删除学习路径         pathId 
/learning-path/behavior        POST        记录学习行为 { pathId, stepId, behaviorType, duration }


### 3.5 智能辅导模块 (src/api/tutor.js)
API路径                    HTTP方法      功能        请求参数 
/tutor/ask                    POST    发送提问   { text, images: [] } 
/tutor/ask/stream        POST   流式提问(SSE)   { text, images: [] } 
/tutor/history                 GET       获取答疑历史   { page, pageSize } 
/tutor/detail/{recordId}   GET    获取答疑详情    recordId 
/tutor/{recordId}        DELETE     删除答疑记录     recordId

### 3.6 学习评估模块 (src/api/assessment.js)

/assessment/stats                  GET     获取学习统计 { startDate, endDate, type } 
/assessment/weak-points      GET      获取薄弱点分析 -
