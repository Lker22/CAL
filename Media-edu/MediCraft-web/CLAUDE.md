# CLAUDE.md

##需求
基于现有业务需求，开发新时代大学生AI学习辅助系统前端项目，技术栈必须使用vue，javaScript，ElementPlus，html，css，除此之外可自行使用其他辅助技术栈，可按需选用适配方案，遵循下述全部业务与开发规范编写代码


## 项目整体业务
核心打造五大全功能模块+公共基础能力
1. 用户动态学习画像模块：对话式自主构建画像，6个基础维度，支持随学随更新，包含登录注册、画像查询编辑、多轮对话交互
2. 多智能体协同资源生成模块：六大角色智能体协作，生成文档、思维导图、题库、实操案例、音视频脚本等5类以上个性化学习资源，附带生成进度追踪
3. 个性化学习路径规划与资源推送：依据画像定制动态学习路线，节点化管理学习步骤，自动匹配推送对应学习资源，可根据学情实时调整方案
4. 智能答疑辅导模块：文字+图片多模态提问，图文视频多种形式答疑，留存答疑历史记录
5. 学习效果评估模块：采集学习行为数据，生成多维度评估报告，依据评估结果优化学习方案
6. 公共模块：文件上传、系统基础配置、全局交互能力

## 界面交互硬性要求
1. 页面风格简约美观，布局逻辑清晰，贴合主流AI产品设计规范
2. 支持内容流式输出、富文本Markdown渲染、多模态内容卡片式展示
3. 异步任务展示加载状态、生成进度，规避空白等待体验问题
4. 具备内容安全展示逻辑，规避违规信息呈现

## 数据关联规则
前端字段、业务逻辑严格匹配后端数据表：
sys_user、student_profile、chat_context、ai_agent、learning_resource、learning_path、learning_path_step、learning_behavior、learning_evaluate、smart_tutor
学习画像展示维度：知识基础、认知风格、学习目标、易错点、学习节奏、资源偏好，同步展示固定信息、动态行为、认知能力、成长趋势四类数据
